# 钢铁校园：黄俊人保卫战

原创 Canvas 2D 无尽模式坦克大战网页游戏。

## 运行

直接双击 `index.html` 即可游玩。也可以在项目目录启动任意静态服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 操作

- `WASD` / 方向键：八方向移动
- 鼠标：瞄准，左键射击
- `J` / 空格：射击
- `1–5`：制式炮弹、激光、巡航导弹、爆裂弹、空对地导弹
- `T`：范围嘲讽
- `P` / `Esc`：暂停；空袭瞄准时取消空袭

## 规则

- 所有弹药均可能伤害任意坦克，包括发射者本人。
- 制式炮弹可在地图边界和防弹钢板上反弹。
- 砖墙、防弹钢板、木箱耐久分别为 5、7、3；水域与地图边界不可摧毁。
- 每波结束自动保存检查点；历史战绩保存在浏览器本地。
- 地图以“黄、俊、人”三个字为核心障碍轮廓，每四波轮换战区。

## 技术说明

项目不依赖第三方库或外部素材，由 `HTML + CSS + JavaScript + Canvas 2D` 构成。游戏逻辑使用固定 60Hz 时间步，视觉资源均为程序化原创绘制。
