# 神也要有简历

黄俊人的全新个人简历网站。项目与原有 `resume-site-optimized` 完全独立，不会修改旧站。

## 使用方式

- 双击 `index.html` 即可离线浏览。
- “代表项目”使用大字号文字索引，不在栏目中直接堆放图片。
- 桌面端将鼠标移到项目名称上可查看跟随式图片预览；点击后打开完整项目详情。
- 手机和平板端无需悬停，直接点击项目名称即可打开详情；坦克大战可从项目详情进入游玩。
- 桌面端在首屏与代表项目区保留图片轨迹，用于补充作品视觉预览；轨迹节点采用对象池复用，并在减少动画模式下自动关闭。
- 全站背景加入可交互的流体噪声层：鼠标与触控可牵引墨流，点击空白区域会产生局部墨花；深浅章节会自动切换配色和混合方式。
- 菜单中的 `FLUID FX` 可随时关闭或重新开启流体效果，选择会保存在本机。
- 点击“打印 / 导出 PDF”，在浏览器打印窗口中选择“另存为 PDF”。

## 性能策略

- `fluid.js` 在页面主体加载完成后的浏览器空闲阶段才按需载入，不阻塞首屏文字、头像和导航。
- 桌面端按设备能力使用 45—60 FPS 的 WebGL2 流体；普通手机使用 30 FPS；较弱设备使用 24 FPS；低内存、低核心数或省流量设备自动切换为 18 FPS Canvas 轻量模式。
- 运行时会监测连续慢帧并自动降低模拟频率与压力迭代次数，避免流体效果拖慢正文滚动。
- 标签页隐藏、弹窗或菜单打开时暂停模拟；不支持 WebGL2 时自动降级，不影响简历内容和项目入口。
- 系统开启“减少动态效果”时默认不加载流体脚本，用户仍可从菜单手动开启。

## 设计说明

视觉语言参考高性能运动员个人网站常见的编辑式排版、荧光强调色、分屏叙事和参数化编号。网站内容基于本人经历与项目，由本人规划并使用 AI 辅助开发；校徽等第三方标识归相应权利人所有。

## 文件

- `index.html`：网站结构与完整内容
- `styles.css`：桌面、移动端与打印样式
- `main.js`：菜单、弹窗、光标、滚动和键盘交互
- `fluid.js`：按需加载的 WebGL2 流体与 Canvas 轻量降级渲染器
- `assets/`：头像与校徽
- `screenshots/`：项目截图
- `game/`：可离线运行的坦克大战项目
- `react-hover-preview/`：React + TypeScript + Tailwind + shadcn 结构的悬停预览组件实验区
